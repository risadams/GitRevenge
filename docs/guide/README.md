# User guide

Git Revenge is a desktop git client for Windows and macOS. It's built to stay quick on very large repositories, and it does all its work through the `git` you already have installed, so your config, hooks, credential helpers and SSH agent all keep working.

There are no accounts, no cloud features and no AI. The only request the app makes on its own is a check for a newer release at startup, and you can switch that off in [Settings](settings.md).

## Where to start

1. [Install it](install.md) and check you have a recent enough git.
2. [Open or clone a repository](repositories.md).
3. Find your way around [the commit graph](graph.md).
4. [Stage and commit](changes.md), then [branch, merge and rebase](branches.md).

The rest of the guide covers [diffs and history](history.md), [remotes, LFS and submodules](remotes.md), and [settings and keyboard shortcuts](settings.md).

## The command palette

Almost everything the app can do is in the command palette. Press <kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on macOS) and start typing. If you're not sure where something lives, look there first.
